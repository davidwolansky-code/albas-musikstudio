# Albas Musikstudio

En liten musikapp för barn i en enda HTML-fil. Öppna `index.html` i webbläsaren.

- 10 instrument: xylofon, piano, gitarr, blås, dragspel, harpa, elbas, tamburin, trummor och orkester
- Alla ljud skapas direkt i webbläsaren (Web Audio), inga ljudfiler och inga externa beroenden
- Lyssna först, spela själv eller fri lek, med rytmbana och poäng
- Fungerar bäst på mobil i liggande läge
